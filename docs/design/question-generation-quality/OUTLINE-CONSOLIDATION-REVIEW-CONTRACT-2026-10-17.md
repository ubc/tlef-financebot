# Fresh review contract for a consolidated outline

## Implemented scope

`structure-consolidation-review.ts` prepares a complete fresh review plan for a
validated explicit-ID consolidation proposal. The existing original-source and
capability review renderer, packer and driver remain authoritative. Every child
objective is reviewed again against its full assigned original sections and
required peers; parent verdicts are obligations, not reusable source proof.

Raw dispatch history must replay from empty progress with exact prompt, raw
response, parsed finding, failure, ID and attempt bindings. Both selected
predecessor credits and unchanged objectives' own credits must survive on fresh
eligible successors. Missing, uncertain, negative or held results withhold the
final projection. Immutable IDs and retirement/lineage records remain separate
from compact display coordinates, which follow the original curriculum order.
Only exact current replayed parser failures become incomplete diagnostics;
binding, budget and unexpected errors are not waived.

`structure-consolidation-budget.ts` provides an earlier impossibility test under
the unchanged full-original renderer. It counts each exact public original JSON
row once, then adds the minimum number of output reservations. Instructions,
peers, escaping and corrections are omitted, so `not-ruled-out` never means that
a complete plan fits. Both helpers require independently supplied expected
inherited limits and a conservative terminal receipt. Neither authenticates its
caller, grants spend permission, or writes data.
