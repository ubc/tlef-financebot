The current experimental review can withhold two overlapping, source-supported
objectives, but cannot yet produce a reviewed replacement. The next change must
repair that supply gap without deleting a distinct operation or treating a
source-credit union as a semantic judgment.

## Implementation sequence

1. Add the separately versioned `source-preserving-outline-consolidation-v1`
   obligation/proposal core. Select two to four explicit supported parent IDs;
   preserve source aliases separately from original corpus IDs, exact old
   findings, recorded credit obligations, stable coordinates and unaffected
   objectives. Allow multiple narrowed survivors, including equal-count
   narrowing. A replacement is an unreviewed draft, never an approval.
2. Add a transaction-required authenticated parent reader. Delegate complete
   raw-history/source/result validation to the existing capability Apply guard,
   bind the exact parent/checkpoint/progress and terminal budget, and reject
   retained-file imports, legacy absence and repair children. File-only
   diagnostic inputs cannot become durable authority.
3. Implement a dedicated durable child link, explicit cycle policy, worker,
   recovery and review state. Build the complete missing source/comparison work
   and measure native input/output/correction reservations before its first
   send. Use the latest authenticated terminal ledger, never the earlier
   measurement prefix. No model work belongs inside a transaction.
4. Recheck changed source wording, credited operations and affected incoming,
   outgoing and newly nominated comparisons. Treat all replacement survivors
   as fresh source targets. Record inherited observations separately from fresh
   reviews. Existing source-only rows are not complete capability reviews.
5. Add dedicated child Apply and Instructor review controls. Replay immutable
   parent/child/source/raw-history/budget/lineage authority in the matching
   course transaction; show lost or unresolved obligations rather than
   silently retiring them. Keep the parent accessible and require explicit
   teacher Apply.
6. Compare frozen real inputs and actual model outputs under an explicitly
   approved paid declaration. Report correct usable supply, source fidelity,
   duplicate/condition/difficulty errors, tokens and elapsed time separately
   from scripted gate tests. Preserve all failures in the English book.
