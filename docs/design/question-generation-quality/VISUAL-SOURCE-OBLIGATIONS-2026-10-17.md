## Problems being investigated

The previous native provenance checks account for 599 physical pages and map all
671 chunks. This establishes exact location, not that chart relationships or
table semantics reached the generator. A footer can make a page appear to have
mapped text while its instructional content remains in a raster image. A chart
can also consist entirely of vector drawing operations, so an image-only detector
would miss it. Conversely, a readable table or decorative title may have many
path operations without needing a vision call.

The actual retained P04 question separately demonstrates a request-fulfillment
gap: requested hard, candidate/reviewer achieved easy, yet historical eligibility
was positive. Difficulty and requested numerical/conceptual kind need distinct
checks from source support, uniqueness, correctness and word count. A positive
quality status alone must not be presented as satisfying the teacher's request.

## File-only inspection contract

- Use the already pinned ten original PDFs, exact retained native text and page
  maps. Validate identities and physical page counts before joining records.
- Preserve one accounting row for every page, including blank, footer-only,
  failed and unprobed pages. No selected queue is a coverage denominator.
- Keep native text density/numerical labels, independently observed PDF text,
  raster paints and vector drawing signals separate. These are observations,
  not a table/graph classifier or an interpretation result.
- Default interpretation to unknown and review to unreviewed. No drawing/text
  heuristic can grant mapped pedagogical coverage or verified numerical values.
- Produce an inspectable diagnostic priority queue of at most six pages and two
  per file. Unselected pages retain their unknown state. The queue does not
  authorize rendering, OCR, a vision call or generating a question.
- Inspect PDFs in bounded child workers with input, memory, time, concurrency
  and output limits. Deny provider, database and network boundaries. Record
  tool/package versions, commands, exact inputs and failed attempts.
- Keep the prototype outside the pinned production runtime. It must not alter
  originals, chunk text, declarations, ledgers or learning records.

## Root visual controls

Five predeclared original-page renders contrast a vector chart, raster table,
readable table, title and risk matrix. The predeclared filename called the second
example a raster chart; actual inspection corrected that hypothesis to a table
without rewriting its historical filename. Four are deliberately from the same chapter
to hold document style constant. This manual diagnostic control set is separate
from the capped future priority queue. These are source-only agent observations,
not blinded teacher labels, exhaustive chart interpretation or a random estimate
of whole-corpus visual quality.

The renderer writes original hash/page identities and PNG dimensions, command,
version and local timing to `audit-results/pdf-visual-obligations-2026-10-17/`.
Original PDF bytes are checked before and after each render. No PDF is authored.
Page screenshots and exact retained native text will be shown together in the
existing English evidence book; explicit observations must identify what the
text does and does not retain, without inventing graph values.

planning, review, bounded repair and persistence. It reports descriptive counts
within the already observed recovered model cohort, keeping unknown responses,
automatic model labels and independent source-only agent findings separate.
These data cannot establish a causal model ranking or professor acceptance.

The additive `task-demand-v1` production change does more than reject easy candidates:
use the existing bounded task/repair budget to request a source-supported inference

shortfall when the permitted source cannot support that task. It must preserve
source scope, no-repeat requirements, model-send budgets and teacher constraints.
See `TASK-DEMAND-IMPLEMENTATION-2026-10-17.md` for the mechanical implementation
