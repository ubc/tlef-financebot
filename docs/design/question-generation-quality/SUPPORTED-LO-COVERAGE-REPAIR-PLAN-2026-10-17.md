## Versioned bounded implementation

Add an internal opt-in `coverage-wording-outline-repair-v1` branch alongside the
existing `wording-only-outline-repair-v1` pilot. Historical inputs keep their
stored mode; unknown explicit modes fail. Both share the same one-cycle unique
parent-checkpoint claim, at most two targets, source/currentness checks, native
send accounting, per-input/output limits and total conservative ceiling. This
does not authorize a new model dispatch or a new browser endpoint.

The request supplies objective IDs and explicit assigned point IDs. The server
requires a completed, fully reconciled original-bound parent, supported target
findings, and requested points that are assigned to that objective but credited
nowhere in the parent. It derives the complete set of previously credited
target points itself. Foreign, already credited, duplicate or empty targets
fail before model work or child writes.

The proposal may change only selected objective wording. It receives complete
unchanged own originals, original teacher constraints and a bounded target brief.
Topics, objective identities/counts, evidence/material/passage scope and sibling
wording cannot change. The new name must preserve useful existing capability and
make the requested missing capability explicit only when its originals support
that interpretation. A legitimate no-repair answer remains a scoped shortfall.

The ordinary independent source/coverage reviewer sees the new wording and exact
originals, without an instruction to accept a target or a prior positive verdict.
Reuse unchanged sibling findings only with their exact old bindings. Before
finalization, replay the full grounded-outline validator and require each changed
target to be supported and credit every requested point plus every previously
credited target point. Extra or forged references never create coverage.

Record a server-computed passed/shortfall receipt in the durable branch before
finalizing. A missing target credit, lost previous credit, no-repair or negative
source verdict makes the child an explicit shortfall; retain raw proposals,
independent findings, costs and diagnostics. Never overwrite or optimistically
relabel the parent outline. A successful child still needs explicit reviewed
Apply through the existing run-bound path.
