# Course Structure prototype
Sample-only interactive design. No API calls or changes to course data.

Compact topic navigation and objective rows; expand an objective for inline editing,
source context, and keyboard-accessible reordering. Course-wide search, all-objectives
overview, topic rename/create, multiline objective creation, empty state, dark mode,
and small-screen layout are available.

Design: retain the existing green shell; white reading surface, quiet blue-gray
borders and muted labels. System sans for controls; restrained Charter topic titles.
The numbered objective outline conveys actual topic/LO order rather than decoration.
Source status is adjacent to each objective, with details disclosed on selection.
