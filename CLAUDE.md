# CLAUDE.md — FinanceBot

FinanceBot has a single developer. This file is loaded into every session; the
full engineering guide is in **AGENTS.md** (and the per-folder `AGENTS.md`
files — always follow the one closest to the files you are editing).

There is no developer-identity question, task ownership, or plan-sharing step:
see AGENTS.md → "Project ownership and plans".

## Write a plan before you build

For non-trivial work, first agree a design with the developer and save it as a
spec under `docs/superpowers/specs/`, then turn it into a task-by-task plan
saved under:

```
docs/superpowers/plans/<phase>/
```
